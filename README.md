# Audio Setup App

Конфигуратор Hi-Fi системы: варианты прослушивания, проверка соединений, каталоги Schiit/Govee, комната и параметрическая мастерская стойки.

## Варианты системы

`/#system` — выбор компонентов и подключения. В разделе «Твои варианты» можно сохранить до 24 именованных конфигураций, переключаться между ними, сравнивать текущие настройки с сохранёнными и отменять изменения тракта (30 шагов в текущем сеансе). Смена тракта не удаляет физические аппараты со стойки. Последний удалённый вариант можно восстановить до перезагрузки страницы.

- Браузер хранит план и библиотеку в `audio-system-workspace-v2`; старый `audio-system-plan-v1` читается при первом открытии и не удаляется. Облачной синхронизации нет.
- «Скачать варианты» / «Загрузить из файла» переносит библиотеку в JSON версии 1. Импорт проверяет весь файл до записи, добавляет варианты без замены текущего тракта и пропускает точные дубликаты. Лимит файла 128 КБ. Мебель экспортируется отдельно в мастерской.
- «Показать другу» у сохранённого варианта передаёт его название, аппараты и подключения в URL. Общая ссылка `/?view=share#room` показывает базовый план; повреждённые и неизвестные конфигурации отмечаются явно, без скрытой замены аппаратов.
- Схема разделяет основной тракт, ветку наушников и подключения двух REL по сведениям владельца. Неизвестные электрические параметры не означают совместимость. Комната остаётся сохранённой сценой из восьми аппаратов, а не автоматическим рендером произвольной конфигурации.
- Мастерская, патч-панель и каталоги загружаются при открытии раздела, движок 3D — при открытии 3D. Для ошибки загрузки раздела есть восстановление через обновление страницы. Подход: [React lazy](https://react.dev/reference/react/lazy), ограничения сохранения: [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage).

## Комната и прогулка

`/#room` и режим просмотра для друга содержат «Фото», «Открыть 3D» и «Прогулка · WASD». В прогулке: WASD / стрелки — движение, мышь — обзор, Esc — пауза. Захват курсора запрашивается только кнопкой «Войти в комнату»; если браузер его не поддерживает, остаётся обзор перетаскиванием. На сенсорном экране работают перетаскивание и кнопки шагов. Есть полный экран, мини-карта и возврат к месту слушателя. Потеря фокуса, скрытие вкладки и выход из раздела останавливают управление.

Камера идёт на высоте 1,63 м; окружность радиусом 20 см ограничена стенами и консервативными контурами стойки, колонок, сабвуферов, торшеров и дивана. Это навигация по интерьерной сцене, не расчёт проходов реальной комнаты. Геометрия для сайта — 46 объединённых объектов, 17 встроенных текстур, около 7 МБ. В обзоре потолок и две ближние стены скрываются; в прогулке комната закрыта.

`scripts/blender/polish_listening_room.py` запускается в Blender 5.2 на сохранённом `audio-setup-listening-room.blend`. Сохраняет самостоятельный `audio-setup-listening-room-polished.blend`, рендер JPEG и GLB. Исходный файл не перезаписывается. Изображения цвета/нормалей дерева и тканей переносятся в GLB; тонкие волокна ковра остаются в Cycles-рендере, а веб использует рельеф и карты нормалей. Интерьер, окно, диван и подвесная люстра — проектный вариант, без присвоения неподтверждённых моделей Govee.

Источники поведения: [Three.js PointerLockControls](https://threejs.org/docs/pages/PointerLockControls.html), [MDN Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API). Автопроверки навигации покрывают стены/препятствия, скольжение, диагональную скорость и скачки времени кадра; всего 38 тестов проекта.

## Запуск

Node.js 20+:

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

Порт из `vite.config.js` по умолчанию 3000. `/#cabinet` открывает мастерскую, `/#patch` — патч-панель, `/#room` — комнату, `/#lighting` — каталог Govee.

## Мастерская

- Прямоугольные деревянные полки: индивидуальная ширина, глубина, толщина, высота и смещения X/Z. Добавление до 10 полок; удаление после переноса аппаратов.
- Выбор детали в сцене или списке, 3D-манипулятор перемещения с шагом 5 мм и точный ввод чисел. Положение техники привязано к полке. Для чисел используется Enter или выход из поля.
- Четыре опоры: редактируемые оси и диаметр декоративных втулок. Узел M16: шпилька, две гайки и две шайбы на каждой полке/опоре. Сквозные отверстия Ø18 следуют за осями опор.
- Дополнительные круглые сквозные отверстия редактируются по координатам и диаметру; они действительно вычитаются из геометрии полки. Ошибочные или пересекающиеся отверстия отмечаются проверкой и не создают некорректную 3D-сетку.
- Виды 3D / спереди / сзади / сбоку / сверху. Ортографические проекции, сетка 50 мм, размеры, X-ray, разнесение деталей, скрытие техники и кабелей.
- Отмена/возврат 50 изменений, Ctrl+Z / Ctrl+Y. Проект сохраняется в localStorage (`audio_workshop_v1`); импорт/экспорт JSON проходит проверку схемы.
- DXF 1:1 в мм: контуры полок и сквозная сверловка. Отдельно CSV деталей/крепежа и сверловки, SVG полки, автономный HTML-альбом для печати/согласования. DXF-детали разложены слева направо; локальная база сверловки — левый передний угол.

Это специализированный параметрический редактор данной конструкции, не универсальное CAD-ядро. Нет произвольных твердотельных операций, пазов/глухой сверловки, STEP и расчёта прочности.

## Кабели

### Укладка в комнате · 05.10.2026

Вторая визуальная итерация: `scripts/blender/naturalize_listening_room.py` запускается на сохранённом `audio-setup-listening-room-cables.blend` и создаёт отдельный `audio-setup-listening-room-natural.blend`. Межблочники свисают свободными U-петлями, тяжёлые шнуры опираются на короткие держатели у заднего края полок и спускаются индивидуальными дугами. Напольные линии имеют разный запас и провисание между шестью мягкими деревянными опорами. Высокая задняя рама убрана. Дополнительные референсы Pinterest: [крепления за полками](https://ca.pinterest.com/pin/38069559342458139/) и [тяжёлые силовые шнуры](https://ca.pinterest.com/pin/321796335875329656/).

Форма задаётся сохраняющей монотонность кубической интерполяцией с непрерывными касательными. Это художественно заданное провисание, а не расчёт жёсткости конкретного кабеля. Проверки 37 трасс учитывают готовые поверхности труб и толщину кабеля у полок; отчёт — `artifacts/blender/natural-cable-report.json`. Фактические длины и распайка не подменяются геометрией. Оплётка получила UV по длине и карты цвета, нормалей и шероховатости. `natural_room_materials.py` также обновляет древесину, рояльный лак, стекло ламп Freya, фактуру ворса, опоры дивана и освещение. Обе фотографии — общий вид и **Кабели крупно** — рендерятся из той же сцены, что экспортируется в GLB. В интерактивной комнате добавлены мягкие контактно-зависимые тени; прогулка сохранена.

Предыдущая итерация и исходник сохранены:

Скрипт `scripts/blender/route_listening_room_cables.py` запускается на `audio-setup-listening-room-polished.blend` и сохраняет отдельный `audio-setup-listening-room-cables.blend`, JPEG и GLB. Он заменяет свободные Bezier AUTO-кривые: они опускались до 50 мм ниже пола между контрольными точками. Новые скругления остаются внутри управляющего многоугольника. Перед экспортом проверяются нижние вершины готовых труб относительно верхней поверхности досок (Z=4 мм), а также зазор по толщине кабеля до полок. Отчёт `artifacts/blender/cable-routing-report.json` сохраняет длины нарисованных трасс и минимальные зазоры. Эти длины не выдаются за измеренные кабели владельца.

Тяжёлые линии AE320 и REL проходят на деревянных опорах с мягкими седлами; питание закреплено за стойкой и разведено отдельно. Запас уложен свободными плавными изгибами. В 3D есть ракурс **Кабели**: задняя стена скрывается только для осмотра. Прогулка сохраняет все стены. Размещение и размеры опор — проект; улучшение звука от опор не заявляется.

Референсы: [Pinterest · Hi-Fi Cable Elevators](https://de.pinterest.com/pin/hifi-cable-elevators--55802482883529658/) — деревянные U-опоры с мягкой вставкой; [Nordost · Length](https://www.nordost.com/faqs-length.php) — свободная укладка лишней длины без тугих бухт; [REL · High Level](https://rel.net/blogs/learn-and-explore/tips-for-connecting-a-rel-subwoofer-high-level) — подключение к тем же акустическим клеммам, что и колонки.

Владелец уточнил: REL берут HIGH LEVEL с общих с AE320 выходов Rusich, на стороне сабов установлены XLR. Схема и патч-панель показывают эти две ветки как сведения владельца. Вход **XLR_HIGH_LEVEL** отделён от линейного XLR; совпадение корпуса разъёма не разрешает такое соединение. Штатный паспорт REL со Speakon сохранён отдельно; распайка XLR, геометрия контактов и электрическая проверка не выдуманы. При выборе другого усилителя ветки остаются проектными. Длины этих двух кабелей в патч-листе — «Не измерена» до ручного ввода.

Пружинная цепочка Rapier заменена геометрическими трассами: её старые коллайдеры игнорировали полки. Аппараты теперь стоят по точным сборочным координатам, а не падают на полки при редактировании.

- 6 сигнальных соединений и 6 линий питания. Для Arcam — профиль Supra LoRad; для прочих сетевых кабелей — редактируемый кастом Furutech; отдельно внешний БП проигрывателя и USB-C 5 В WiiM.
- Сечение, масса на метр, масса/габариты разъёмов, минимальный радиус, прямой участок за разъёмом, доступная длина, монтажный запас, шаг держателей.
- Питание уходит в боковую зону за стойкой, сигнал — в отдельные глубинные плоскости. Автомаршрут либо собственные управляющие точки XYZ. Повороты построены круговыми дугами с заданным радиусом; невозможный радиус даёт ошибку, не скрытую деформацию сплайна.
- Расчёт длины по оси, массы и веса пролёта между держателями. Запас длины включается в спецификацию, но не рисуется петлёй.
- Проверки пересечений трассы/разъёмов с габаритами полок, стоек и техники, пересечения пола, короткого кабеля, невозможного радиуса и излома у разъёма. Проверка полок консервативна: отверстия не используются как разрешённые кабельные проходы.
- Держатели и задняя сервисная рама показаны как проект размещения. Соединения рамы с мебелью, модели БП/распределителя и несущие кронштейны нужно спроектировать отдельно. Линия RCA/XLR обозначает соединение; точная геометрия парных L/R вилок пока не моделируется.

Нет расчёта провисания/жёсткости/усилия изгиба, взаимных столкновений кабелей и электромагнитной совместимости. Заданный разнос зон не означает гарантированный зазор между каждой парой кабелей около разъёмов. Это не симулятор акустического качества.

### Исходные данные

Владелец указал Supra LoRad для Arcam, кастомные Furutech для других аппаратов, внешний БП проигрывателя (напряжение неизвестно), USB-C у WiiM. Конкретные кабели/вилки и фактические длины не измерены.

- [Supra LoRad 2.5](https://supracables.se/datasheets/se/Power-cables/lorad-cable-2_5-cs-16-eu-angled-datasheet-se.pdf): Ø11 мм относится к этому варианту; не подтверждает вариант кабеля владельца.
- [Furutech FP-3TS20](https://furutech.com/ja/product/fp-3ts20/): Ø14,3 мм — пример исходного габарита, не идентификация кастомного кабеля.
- [Belden 5100UP](https://catalog.belden.com/techdata/EN/5100UP_techdata.pdf): пример паспортного радиуса для конкретной конструкции. Его значение не перенесено на Supra/Furutech.
- [Hirschmann / Belden](https://catalog.belden.com/prodimgs/AllAssets-approved/std.lang.all/65/32/PDF_786532.pdf): разделение силовых и сигнальных трасс, короткое совместное прохождение и пересечения под 90° как инженерный ориентир.
- [WiiM](https://www.wiimhome.com/wiimpro/overview): USB-C для питания 5 В.

Масса кабелей/разъёмов, R60/R100, длины 2/2,5 м и шаг держателей 220 мм — редактируемые допущения, не паспортные значения. Координаты разъёмов приближённые и имеют поправки XYZ.

## Перед изготовлением

Файлы имеют статус **для согласования**, не выпуск в производство. Проверить прогиб и устойчивость, смятие/влажностные деформации древесины, площадь шайб, материал и класс крепежа, фактические габариты техники, вентиляцию и зазоры. Выбрать артикулы ножек и держателей, разработать заднюю раму и лоток блоков питания. В альбом автоматически включаются ограничения и найденные геометрические ошибки.

## Архитектура

- `src/data/workshop.js`: версия/схема проекта, каталог соединения M16, детали, отверстия, проверки мебели, BOM.
- `src/data/cableRouting.js`: круговые сопряжения, маршруты, длина/масса/опоры, проверки габаритов.
- `src/data/workshopExport.js`: единая сверловка для SVG/DXF/CSV, HTML-альбом.
- `src/stores/useWorkshopStore.js`: изменения проекта, 50 шагов истории, сохранение и импорт.
- `CabinetPanel`, `CabinetView3D`, `ShelfMesh`, `RackFrame`, `RoutedCables`: интерфейс и сборочная геометрия. Не обновлять состояние родителя на mouseDown манипулятора: это пересоздаёт привязку Drei во время захвата. Изменения фиксируются на mouseUp.
- `cabinetSpecs`, `cabinetLayout`: каталог техники и исходная компоновка для первого проекта. Старые `EquipmentBox`, `PhysicalCable`, `ShelfValidator` остались историческими компонентами и не участвуют в сцене.
- Патч-панель (`src/store/routingStore.js`) пока использует отдельный список соединений. Изменение режима прослушивания не переписывает монтажный проект.

## Проверки

38 автоматических тестов: сохранение и миграция настроек; версия проекта и импорт; undo/redo; компоновка; точность кругового радиуса; коллизии и слишком короткие трассы; совпадение сверловки и единиц DXF/SVG/CSV; экранирование текста в альбоме; электрические проверки; сохранение всех восьми аппаратов; библиотека вариантов, атомарный импорт, отказ хранилища, ссылки и разделение веток сигнала.

В браузере проверены изменение ширины, добавление отверстия и SVG, 3D-перенос полки с записью высоты, предупреждение о коротком кабеле и возврат через undo, сохранение после перезагрузки. Также проверено отображение на экране 390×844; камера оставляет место для размерных подписей.
